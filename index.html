Help Center

Logging in

Lecturer: type the lecturer username and password, then tap Lecturer Login.
Admin: tap Admin Login under it, then use username + password or your fingerprint.

Admin can

  • Register, edit, delete, import and promote students (Admin Dashboard).
  • Manage courses, results, attendance, timetable, announcements and support tickets.
  • Upload, replace, rename or delete ND1/ND2 papers for every department (Departmental).
  • Change the Lecturer and Admin usernames/passwords, add accounts, register fingerprint, choose what lecturers can open (Accounts Control).
  • Back up and restore all data.

Lecturer can

  • Search students, manage courses, enter and publish results, mark attendance.
  • Post announcements, answer support tickets, view documents and reports, view department papers.
  • The Admin decides exactly which of these a lecturer may open.
